description=
description=[h1]Stop clicking "Saw Logs" twelve times.[/h1]
description=Right-click a stack, pick [b]Saw Logs (All 12)[/b], and walk away. Every recipe in the right-click menu gets an [b](All N)[/b] option that runs it on the whole stack.
description=
description=[img]https://raw.githubusercontent.com/HxHippy/pz-craft-whole-stack/main/docs/wholestack-menu.png[/img]
description=
description=[h2]How to use it[/h2]
description=[list]
description=[*]Right-click any stack in your inventory or a container.
description=[*]Pick the recipe with [b](All N)[/b] after it. N is how many you can actually make right now.
description=[*]That's it. Cancel any time by moving, like any other action.
description=[/list]
description=
description=[img]https://raw.githubusercontent.com/HxHippy/pz-craft-whole-stack/main/docs/wholestack-progress.png[/img]
description=
description=[h2]Smart about it[/h2]
description=[list]
description=[*][b]Real counts.[/b] N accounts for your tools, your inputs, and your carry weight. No queue that dies halfway.
description=[*][b]Selection-aware.[/b] Select 5 of 20 cans and it opens 5. Right-click one and it uses everything you have.
description=[*][b]Pulls from crates.[/b] Recipes that need items on you pull the stack from the container first, only as much as you can carry.
description=[*][b]Plays by the rules.[/b] It only appears on recipes the game allows batch crafting for, the same rule as the crafting window's quantity box.
description=[/list]
description=
description=[h2]Multiplayer[/h2]
description=Works on dedicated servers. It uses the game's own batch-craft path, the same one behind the crafting window's quantity box, so the server validates every craft. No new network code.
description=
description=[h2]Compatibility[/h2]
description=[list]
description=[*]Build 42 only.
description=[*]Client-side Lua. Safe to add to or remove from an existing save.
description=[*]Works with any mod that adds normal B42 craftRecipes.
description=[/list]
description=
description=[h2]Pairs well with[/h2]
description=[b]Craft Planner[/b]: pick anything to build and get the whole plan, down to the last log.
description=
